# Pulsar Music Gen

Turn the provided link into a finished MP3. Use the user's output directory, or `~/Downloads/Music`; name it `Artist - Title.mp3` with filesystem-safe characters. Ask for the link if missing. Treat a playlist link as one selected track unless the user requests the whole playlist. Preserve existing files by choosing a unique filename.

1. Read and use the installed `watch` skill, including its setup and authentication instructions. Run its video workflow with `--max-frames 12 --out-dir <working-directory>`, keeping transcription enabled: native timestamped captions first, local Whisper fallback. Inspect every returned frame. Keep the downloaded video, captions/transcript, and `download/video.info.json` until the MP3 passes verification. Reuse these files rather than downloading again.
2. Read the raw info JSON and available credits. Set title and artist from explicit music credits, then reliable title/description evidence; user-provided corrections take priority. Do not mistake the uploader for the artist. Resolve the album name from explicit release credits or a verified Apple Music release matching the exact recording, including its version; preserve the official single or EP name when applicable. If the album cannot be established, ask the user for the album name or explicit approval of a fallback before writing tags. Never leave the album blank or use `Unknown Album` as a placeholder. Include album artist, release date, track/disc numbers, genre, composer, and copyright only when supported. Do not substitute upload date for release date. Preserve the original source URL in a comment. If title or artist cannot be established, ask for the missing credit; never invent tags.
   Look up each credited artist on Apple Music and verify the identity against the track, release, and credits, rather than accepting a name-only match. Use the exact artist name displayed by Apple Music, preserving spelling, capitalization, punctuation, and diacritics, for artist tags and the corresponding album artist tag when applicable. Show the user the matched Apple Music artist link and ask them to confirm the identity before writing tags. If the match is ambiguous, unavailable, or absent, ask for the correct Apple Music artist link or explicit approval of a fallback name; do not silently substitute an uploader or a guessed name.
3. Use watch's 512px preview frames only to choose a scene, never as cover art. Watch normally downloads at most 720p: inspect available video formats and compare their actual dimensions with the downloaded source. If a better source exists, download the highest-resolution video-only format separately, using watch's authentication rules; keep the original download for audio. Verify the downloaded dimensions with `ffprobe` rather than trusting a format label. If the better source is unavailable, report the limitation instead of silently claiming full quality.
   Extract several nearby frames directly from the best source at their timestamps as lossless PNGs. Choose the sharpest representative frame with a strong square composition; avoid black frames, transitions, motion blur, compression damage, and obstructive overlays. Crop around the subject at native resolution without stretching or upscaling. Aim for at least 1000×1000 when the source and composition allow; use the largest clean square available and disclose smaller dimensions. Preserve key text and the subject; try another timestamp or crop when necessary. Inspect the square at native resolution, then encode once as a high-quality RGB JPEG (Pillow quality 95, subsampling 0, or equivalent). Do not use screenshots of a player, recompressed previews, or artificial sharpening to disguise missing detail. Prefer actual video imagery over a platform thumbnail. If no usable video frame exists, explain and ask for cover art. Report the source dimensions and final square dimensions when delivering the MP3.
4. Use `ffmpeg` to encode the original audio with `libmp3lame -q:a 0`, preserving its channel layout. Never use watch's mono transcription audio. Embed the JPEG as ID3v2.3 front cover art, alongside the verified tags. The cover must be inside the MP3, not just a sidecar or a Finder icon. A command shape is:

   ```sh
   ffmpeg -n -i "$video" -i "$cover" \
     -map 0:a:0 -map 1:v:0 -map_metadata -1 \
     -c:a libmp3lame -q:a 0 -c:v copy -id3v2_version 3 \
     -disposition:v:0 attached_pic \
     -metadata title="$title" -metadata artist="$artist" \
     -metadata album="$album" \
     -metadata comment="$source_url" \
     -metadata:s:v:0 title="Album cover" \
     -metadata:s:v:0 comment="Cover (front)" "$output"
   ```

   Copy the finished JPEG into the MP3 without re-encoding it. Add supported optional tags as separate arguments. Use properly quoted arguments or a subprocess argument list for all source-derived values. Do not trim, normalize, or otherwise alter the music unless requested.
5. Obtain lyrics from user-provided or authorized lyric sources when available; otherwise transcribe the downloaded audio locally using watch. Match the exact recording, including live, remix, explicit, or clean versions. Check captions/transcription against the vocals, correct only supported words, retain repeated choruses, and omit instrumental hallucinations. Preserve the original language. Mark uncertain words in the transcript; never present uncertain transcription as official lyrics. For an instrumental, report that no lyrics apply.
   Align each sung line to its audible start in the actual downloaded recording, preserving intros, pauses, and repeated sections. Review the opening, middle, ending, and every uncertain passage; refine coarse caption/Whisper segments by listening or alignment rather than assigning evenly spaced or invented times. Save plain lyrics as `<basename>.lyrics.txt`, a timestamped transcript as `<basename>.transcript.json` with start/end seconds and text, and UTF-8 `<basename>.lrc` with `[mm:ss.xx]` line timestamps. Record lyric/transcription provenance and unresolved uncertainty in the JSON. If reliable text or timing cannot be obtained, report the gap and ask how to proceed instead of claiming completion.
   After encoding, use `mutagen.id3` to embed plain lyrics in a `USLT` frame and timed lyric lines in a `SYLT` frame (UTF-16, appropriate three-letter language code or `und`, timestamp format 2 for milliseconds, content type 1 for lyrics). Save as ID3v2.3 while preserving all existing metadata and cover art. Read both frames back and compare them to the saved text/timestamps. Use an isolated Python environment if mutagen is missing.
   Apple Music supports custom plain lyrics; do not promise that imported MP3 `SYLT` frames or LRC sidecars will produce Apple's scrolling lyrics or Sing features. Provide the LRC for compatible players. Include instructions to import the MP3 into Music and view Get Info > Lyrics; if embedded lyrics are not picked up, paste the saved plain text into Custom Lyrics. Do not alter the user's Music library automatically. Claim Apple Music display or timed playback was verified only if actually checked there. See [Apple's custom lyrics guide](https://support.apple.com/guide/music/view-and-enter-lyrics-musf438ffc97/mac) and [Mutagen's ID3 frames](https://mutagen.readthedocs.io/en/latest/api/id3_frames.html).
6. Verify with `ffprobe` that the output contains MP3 audio, expected duration and tags, and one square JPEG stream with `attached_pic=1`. Confirm the album tag matches the resolved or user-approved album name and is neither blank nor `Unknown Album`, including after the final tag save. Decode the audio to check for errors. After the final tag save, extract the embedded cover without re-encoding, confirm its bytes match the approved JPEG, and inspect it at native resolution. Verify embedded lyrics, monotonic timestamps within the audio duration, and lyric sidecars after the final tag save. Resolve failures before reporting success. Delete only this run's temporary files after verification; retain the final MP3 and lyric/transcript sidecars. Return clickable file links with the artist, title, lyric source, timing confidence, and Apple Music viewing instructions.
