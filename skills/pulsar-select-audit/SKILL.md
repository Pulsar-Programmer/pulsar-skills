# Pulsar Select Audit

Audit only the selected change, UI, or feature; ask which one if unclear. Run the relevant revision, open the affected screen, and exercise the interaction needed to show it.

Capture and inspect one sharp, focused browser screenshot of the selected state. Show it inline with a brief caption, observed defects, and any blockers. Use the environment's preferred browser tools.

Preserve source and uncommitted work; use disposable data. Do not fix anything or expand into a full audit.
