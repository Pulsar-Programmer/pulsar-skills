# Pulsar UI Reuse

Reuse existing UI components across the codebase. Do not create your own. Treat frontend work as moving, reusing, and wiring what already exists.

After UI changes, capture and inspect screenshots of the affected views. Check padding, gaps between components, alignment, and clipping against existing UI patterns. Fix inconsistencies using existing components and spacing tokens, then capture again to verify.
